# Tiptoe Thief

An original 3D top-down stealth game: sneak into houses at night as Tip the
thief, take the loot and get back to the van without being caught.

## Layout
- `assets/models/*.obj` + `materials.mtl` - every 3D object (generated by `tools/make-models.mjs`)
- `assets/textures/*.jpg|png` - every texture (generated by `tools/make-textures.py`)
- `assets/audio/*.mp3` - every sound and the music (generated by `tools/make-audio.py`)
- `src/engine` - renderer, OBJ loader, input, audio
- `src/game` - level builder, pathfinding, thief, guards, security, levels
- `src/ui` - HUD, menus, text
- `src/platform` - CrazyGames, Playgama, YouTube Playables and own-website adapters

## Build
```
npm install
node tools/make-models.mjs && python3 tools/make-textures.py && python3 tools/make-audio.py
node tools/build-platforms.mjs     # builds/<platform>/
node tools/package-zip.mjs         # dist/tiptoe-thief-<platform>.zip
```
Tests (serve the folder on port 8770 first): `tools/test/levels.mjs`, `tools/test/play.mjs`, `tools/test/mobile.mjs`.
