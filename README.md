# Games

- `Backrooms/` — Backrooms - FPS (three.js tactical shooter). Builds for CrazyGames (Full and Basic), YouTube Playables and Playgama. Run the tools from `Backrooms/tools`, and serve `Backrooms/` on port 8765 for the tests.
- **Voxel Isles** (`VoxelIsles/`): blocky minigame game with Sky Islands and Egg Defense, bot-filled lobbies. Build with `cd VoxelIsles/tools && npm install && node build-platforms.mjs && node package-zip.mjs`.
